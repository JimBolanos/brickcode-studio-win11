RCX firmware
============

The RCX needs its firmware loaded once, and it loses it whenever you take
the batteries out. If the display shows only a number and no running
figure, that is what is missing.

  firm0309.lgo   RCX 1.0   - use target RCX
  firm0328.lgo   RCX 2.0   - use target RCX2  (this is the usual one)
  firm0332.lgo   RCX 2.0   - a later build, also target RCX2

From BrickCode Studio: Settings -> Brick utilities -> choose the file
with the "..." button -> "Send firmware".

It takes 3 to 5 minutes. Keep the RCX switched on, close to the tower,
pointing at it, and do not move it. Fresh batteries help.

The firmware is LEGO's. These copies are the ones shipped with the nqc
project and with beckmx/lego-tower-rcx, included so the install works
without a network connection.
